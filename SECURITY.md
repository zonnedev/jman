# Security policy

## Supported versions

Security fixes are provided for the latest published JMAN release and the latest
JMAN Java Marketplace release, including their active pre-release channels.
Older development builds are not supported.

## Reporting a vulnerability

Do not report suspected vulnerabilities through a public issue. Use GitHub's
private vulnerability reporting for the `zonnedev/jman` repository. Include a
clear description, affected versions, reproduction steps or a proof of concept,
and the potential impact. Remove credentials and unrelated private data.

The project will acknowledge a complete report, investigate it, and coordinate
remediation and disclosure with the reporter. Timelines depend on severity and
the complexity of producing and validating a safe release.
